# BuildWise AI — Roadmap

## Phase 0 — Foundation
Repository, client/server structure, TypeScript, lint/typecheck, env configuration, Prisma, database baseline, health endpoint, UI design system, project documentation.

## Phase 1 — Product Shell
Landing page, app layout, sidebar/navigation, responsive design, routes, loading/error/empty states.

## Phase 2 — Site Selection
Leaflet map, marker selection, coordinates, geocoding/search, site requirements form, validation.

## Phase 3 — Data Providers
Geocoding, OSM/Overpass, elevation, Open-Meteo, SunCalc, normalized provider interfaces, caching, timeouts, attribution.

## Phase 4 — Analysis Engine
Slope, terrain, water/flood-risk indicator, accessibility, facilities, environmental indicators, weighted suitability, data confidence, deterministic explanations.

## Phase 5 — Orientation
Solar calculations, wind input, candidate orientation evaluation, planning orientation score and explanation.

## Phase 6 — Cost
Configurable base rates, quality/terrain multipliers, preliminary cost range and transparent breakdown.

## Phase 7 — Results Dashboard
Overall score, factor cards, charts, terrain/environment, orientation, cost, risks, confidence, sources.

## Phase 8 — Report + Compare
PDF generation, report formatting, optional two-site comparison.

## Phase 9 — Quality + Deployment
Unit/integration tests, security review, production build, CI/CD, frontend/backend deployment, managed PostgreSQL/PostGIS.

## Future
Optional auth/history, 3D, zoning/regulation integrations, improved soil data, real-time material prices, mobile app, ML only if explicitly approved later.
